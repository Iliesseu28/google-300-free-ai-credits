# Step 5. Connect n8n

Two ways, both paid by your $300 credit.

## 1. Create the credential once

n8n, **Credentials**, **Add credential**, **Header Auth**:

| Field | Value |
|---|---|
| Name | `X-API-Key` |
| Value | your proxy key |

Call it `Vertex proxy`. Every HTTP Request node below uses it.

Proxy URL from n8n:

| Where the proxy runs | URL to use in n8n |
|---|---|
| Same Docker network as n8n (recommended) | `http://vertex-proxy:8080` |
| Same machine, n8n in Docker, proxy on the host | `http://host.docker.internal:8080` (Linux: add `extra_hosts: ["host.docker.internal:host-gateway"]` to n8n) |
| Cloud Run or behind HTTPS | `https://your-proxy-url` |

## 2a. The OpenAI Chat Model node (AI Agent, chains)

The n8n **OpenAI** credential accepts a custom base URL:

| Field | Value |
|---|---|
| API Key | your proxy key |
| Base URL | `<proxy URL>/v1` |

Then in the **OpenAI Chat Model** node, type the model name by hand (choose *By ID*): `gemini-3.8-flash`.
Your AI Agents, summarizers and classifiers now run on Gemini, billed to the credit.

## 2b. The HTTP Request node (images, voice, video, JSON mode)

| Setting | Value |
|---|---|
| Method | `POST` |
| URL | `<proxy URL>/v1/image?binary=1` |
| Authentication | Generic credential type, Header Auth, `Vertex proxy` |
| Send Body | JSON: `{"prompt": "{{ $json.prompt }}", "aspect_ratio": "9:16"}` |
| Options, Response, Response Format | **File** (for `?binary=1`) |
| Options, Timeout | `120000` (images, voice), `600000` (video with `wait`) |

The image, the WAV or the MP4 lands as n8n binary data: send it to Google Drive, Telegram, S3,
Instagram, a Supabase bucket, anything.

## Ready-made workflow

Import [`n8n/content-pipeline.json`](../n8n/content-pipeline.json) (**Workflows**, **Import from file**):

```
                                            ┌─► Illustrate it (image)
Manual Trigger ─► Topic ─► Write a caption ─┤
                                            └─► Read it aloud (voice)
```

After import: open each HTTP node, select your `Vertex proxy` credential, and replace
`http://vertex-proxy:8080` if your URL is different. Click **Test workflow**.

## Tips from production

- **Several workflows?** Give each project its own proxy key (`PROXY_API_KEYS=key1,key2`). A leaked
  workflow export then costs you one key, not everything.
- **Never share an exported workflow JSON without checking it**: keys typed directly into nodes are
  exported in clear. Credentials are not. Always use credentials.
- **Images in batches:** the free trial allows only a few images per minute. Add a **Wait** node of
  20 seconds between images, or loop with **Split in Batches** of 1. Never run two image batches in parallel.
- **Long videos:** use the two-step flow (start, then poll `/v1/video/status` in a loop with a Wait node)
  rather than one request that waits several minutes.
